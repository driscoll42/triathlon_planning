# `EXP-005`: Multi-Device FIT Ingestion Parser and Hardware Invariant Validation

> **Status:** `QUEUED` (`QUEUED_SPEC`) — Empirical validation companion to Phase 4 `TASK-024` (`src/triplan/io/fit_ingest.py`). Validates every hardware telemetry rule in `SPEC.md` §3, `ADR-010`, and `HEUR-005..007`.

## 1. Objective & Pre-Registered Hypothesis
- **Objective:** Validate the multi-device `.fit` activity parser (`src/triplan/io/fit_ingest.py`, `TASK-024`) against both deterministic synthetic `.fit` fixtures and the athlete's 2,020 local recorded activity files (`data/garmin/activities/fit_files/`) across Garmin Enduro 3, Garmin Edge 530, Garmin Swim 2, Stryd Model 17 Foot Pod, and Tacx Neo 2T Smart Trainer.
- **Null Hypothesis ($H_0$):** The parser fails to disambiguate Stryd Connect IQ developer `Power` from Garmin native `record.power`, miscalculates pool swim duration/sTSS by using `session.total_elapsed_time` or including drills in SWOLF, fails to deduplicate dual-recorded rides within a 300s window, or crashes on malformed/legacy `.fit` records in the 2,020-file local archive.
- **Alternative Hypothesis ($H_1$):** The parser achieves 100% pass rate on all 6 synthetic invariant fixtures, parses 100% of non-corrupt `.fit` files in `data/garmin/activities/fit_files/` without unhandled exceptions, extracts Stryd CIQ `Power` (`is_dev == True`, `field.name == 'Power'`) with zero leakage from native `record.power`, computes active swim duration within $\le 1\text{s}$ of sum of `length_type == 'active'` lengths, and eliminates 100% of overlapping ride duplicates within $|\Delta t_{\text{start}}| < 300\text{s}$.

## 2. Pre-Flight Ceteris-Paribus Hygiene Checklist
- [ ] **Environment Quiescence:** Offline local execution only; zero network calls.
- [ ] **Cold vs. Warm State Control:** Synthetic `.fit` fixtures generated deterministically in-memory/tmp_path; real `.fit` archive (`data/garmin/activities/fit_files/`) read strictly in read-only mode.
- [ ] **Sample Size & Rigor:** 6 synthetic hardware-invariant fixtures + full corpus sweep across all $N = 2,020$ local `.fit` activity recordings on disk.

## 3. Non-Goals & Safety Bounds
- **DO NOT** read `config/*.env` or make network requests.
- **DO NOT** modify or commit any file under `data/garmin/` or `data/fit_files/` (remember: `data/fit_files/` holds 643-byte 80/20 structured-workout definitions, whereas `data/garmin/activities/fit_files/` holds recorded activities).
- **DO NOT** expose personal GPS coordinates or raw PII in `docs/experiments/EXP-005.md`; report aggregate field counts and device matrices only.

## 4. Control vs. Treatment Matrix & Test Corpus
- **Workload / Dataset:**
  1. **Synthetic Fixture Suite (`tests/test_fit_ingest.py`):**
     - *Fixture A (Stryd Model 17 vs Native Run Power):* `.fit` run containing both native `record.power = 310W` (+24% inflated) and CIQ developer field `Power = 250W`, plus `Form Power`, `Leg Spring Stiffness`, and `Air Power`.
     - *Fixture B (Treadmill Run):* `sub_sport == 'treadmill'` with `Air Power = 0W`, verifying treadmill flag without error.
     - *Fixture C (Pool Swim Active Lengths & Drills):* Pool swim with active lengths, rest lengths (`length_type == 'idle'`), and drill lengths (`swim_stroke == 'drill'`, `total_strokes = 0`), verifying active-only duration/sTSS and drill-excluded SWOLF (`HEUR-007`).
     - *Fixture D (Dual-Device Ride Deduplication):* Edge 530 and Enduro 3 ride files starting $120\text{s}$ apart ($< 300\text{s}$), verifying deterministic retention of the Edge 530 recording (`ADR-010`).
     - *Fixture E (Tacx Neo 2T Stream Hygiene):* Indoor trainer ride with erratic `left_right_balance` spikes and coasting zeros (`0W` records), verifying `left_right_balance` is ignored (`HEUR-006`) and zero-power records are included in NP/average power.
     - *Fixture F (7-Zone Time-in-Zone Mapping):* Second-by-second power stream mapped against canonical 80/20 7-zone boundaries ($Z_1, Z_2, Z_X, Z_3, Z_Y, Z_4, Z_5$) anchored to locked $CP$ (`SPEC.md` §2).
  2. **Historical Corpus Sweep (`data/garmin/activities/fit_files/`):** All 2,020 recorded activities (2013–2026) tabulated by device, sport, native fields, and CIQ developer fields.
- **Condition 1 (Control Baseline):** Naive summary/session extraction (`session.avg_power`, `session.total_elapsed_time`, no 300s deduplication).
- **Condition 2 (Treatment A):** Full hardware-invariant parser `triplan.io.fit_ingest` enforcing `SPEC.md` §3 and `ADR-010`.

# `EXP-010`: Run/Walk Re-Entry Library Rows On The TASK-023 Impact Model

## 1. Objective & Pre-Registered Hypothesis
- **Objective:** `TASK-058`. `EXP-008` Finding 6 left walk-jog out because the canonical schema has no walk component and a typed-in reduced impact load would loosen the in-model running-ACWR / strain rows. Author `RUN_RW_*` rows whose load comes from `physiology/load_model.run_walk_mechanical_strain` (the `TASK-023` impact model, `needs_review` priors), and measure whether `CURRENT_ATHLETE` re-entry weeks pick them.
- **Null Hypothesis ($H_0$):** The rows are never picked, or picking them changes single-run weeks / raw running ACWR not at all, or breaks a Tier-0 / 80/20 check.
- **Alternative Hypothesis ($H_1$):** Every row is picked on `CURRENT_ATHLETE`, single-run weeks and raw running ACWR fall, 0 fallback and 0 violations in all 8 seasons, and no solver row, bound or profile field changes.

## 2. Pre-Flight Ceteris-Paribus Hygiene Checklist
- [ ] **Environment Quiescence:** NOT met: another agent's season matrix was running on the machine (one python process at 900+ CPU-s). Wall times are indicative only.
- [x] **Cold vs. Warm State Control:** one process per season, deterministic solve per week (`ADR-018`), library loaded fresh per process.
- [ ] **Sample Size & Rigor:** n = 1 per cell. The 3.5 s HiGHS per-week limit makes tail weeks time-dependent: the `reference` seasons (no run/walk row is ever offered there, candidate pool 98 in both runs) moved 19 -> 11 / 14 -> 14 / 19 -> 18 / 23 -> 20 relaxations between control and treatment, so a relaxation delta of that size is noise.

## 3. Non-Goals & Safety Bounds
- No change to `solver/*`, the safety rows, `ADR-022` run caps, the profile, the load-model constants or the ladder. The only control-layer change removes candidates (`filter_walkjog_workouts`).
- Walked minutes are never given a *lower* duration, TSS or ANS than running them: duration and TSS count walking as Zone 1 running; only mechanical strain (and the neuro / axial loads that follow it) use the walk dose.
- `needs_review` until `EXP-006` calibrates the walk dose against actuals.

## 8. Architectural Conclusion & Action Taken
**Verdict: H1 holds (`COMPLETE_ADOPTED`), with the limits below.**

1. **Representation.** A run/walk session is a `Run` row whose walked minutes are Zone 1 minutes (brisk walking sits below the Zone 1 run band; 80/20 low intensity, zero ANS). Only the impact load differs from a continuous Zone 1 run, and it is computed (`build.run_walk_strain`), never typed. No schema column was added.
2. **Nothing the solver reads is loosened.** `duration_min` counts walking as running (run-minute guard, `ADR-022` longest-run cap, run share, weekly run-minute ramp), `tss` is the aerobic TSS of all minutes at Zone 1 run intensity, strain is strictly above the run minutes alone and strictly below the continuous run of the same length (`tests/test_run_walk_rows.py`). The relief is only strain (and neuro / axial, which follow it by the ordinary non-heavy-run rule).
3. **Ladder gate.** `filter_walkjog_workouts` offers a row only when the week's `WALKJOG_LADDER` rung allows its run share and session length (rung 1: only 1:1 x 20; rung 2: + 2:1 x 20; rung 3+: all four) and offers none at rung 0 (not re-entering). It only removes candidates, which keeps the reference pool at 98 and enforces the 1:1 -> 4:1 progression that `ADR-036` defined but only reported.
4. **Effect on `CURRENT_ATHLETE`:** every row was picked in every season (3-15 times), single-run weeks fell 5-6 -> 3, raw running ACWR 1.45-1.46 -> 1.41, ODI at 70.3 / ironman 1.12 / 1.15 -> 0.95 / 0.99. Relaxations did not move (56 / 62 / 54 / 57 in both): the binding relaxations are the two dropped anchors and the ACWR-floor waiver, which no run row fixes. The in-model ACWR row is unchanged; the improvement is in the *raw* ratio the athlete would actually experience.
5. **Honest limits.** the remaining relaxations (dropped 180 min ride / 75 min run anchors, ACWR-floor waiver) are not library-fixable; the walk dose (cadence, GRF, exponent, x2 safety factor) is a literature-scale prior and the rows are `needs_review` until `EXP-006`; the 3:1 / 4:1 rungs (35 min) have no row (the 30 min 2:1 row serves rungs 3-4). Unaffected: the run frequency minimum counts a run/walk session as a Run session.
6. **Safety:** 0 fallback, 0 violations in 8 seasons; no bound relaxed.
